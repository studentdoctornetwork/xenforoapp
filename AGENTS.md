## SDN delivery ethos

Build the simplest secure solution that works, follow the latest approved SDN
design style (currently Design 5), prove it with focused tests, and move it toward
production. Read [the shared ethos](../sdn-harness/docs/sdn-delivery-ethos.md) at task startup and pass it to
subagents. It supersedes conflicting process guidance; existing safeguards remain.
